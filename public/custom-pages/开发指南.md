# 自定义页面开发指南

本文档用于说明 `public/custom-pages` 目录下自定义页面的开发、发布和接入方式。自定义页面适合在不重新构建主应用的情况下，交付客户现场页面、轻量业务看板、说明页、报表页、外部系统入口或少量定制功能。

## 目录定位

自定义页面统一放在：

```text
public/custom-pages/
```

主应用默认读取：

```text
public/custom-pages/manifest.json
```

构建后这些文件会被复制到 `dist/custom-pages/`。生产环境修改自定义页面时，通常只需要替换 `custom-pages` 目录中的页面文件和 `manifest.json`，不需要重新构建主应用。

## 接入流程

1. 在 `public/custom-pages/manifest.json` 中注册页面。
2. 在系统菜单配置中新增菜单，菜单类型选择“扩展页面”。
3. 在“扩展页面”下拉中选择 manifest 中配置的页面。
4. 在角色权限中给对应角色授权这个菜单。
5. 刷新前端或重新进入菜单后访问页面。

扩展页面的菜单路径格式为：

```text
custom/<页面 name>/<页面 path>
```

实际浏览器访问路径为：

```text
#/custom/<页面 name>/<页面 path>
```

例如：

```text
custom/demo/index
#/custom/demo/index
```

## manifest 配置

`manifest.json` 支持两种格式，推荐使用对象格式：

```json
{
  "pages": [
    {
      "name": "demo",
      "path": "index",
      "title": "自定义页面示例",
      "icon": "Document",
      "sfc": "demo/index.vue",
      "version": "1.0.0",
      "props": {
        "apiUrl": "/api/Demo/List"
      }
    }
  ]
}
```

也兼容数组格式：

```json
[
  {
    "name": "demo",
    "path": "index",
    "sfc": "demo/index.vue"
  }
]
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 页面名称，会用于路由。只保留字母、数字、下划线和中划线，其他字符会被替换成 `_`。 |
| `path` | string | 否 | 页面路径，默认为 `index`，支持 `report/month` 这类多级路径。 |
| `title` | string | 否 | 页面标题，菜单配置下拉中用于展示。默认使用 `name`。 |
| `icon` | string | 否 | Element Plus Icons 图标名，默认 `Document`。 |
| `enabled` | boolean | 否 | 设置为 `false` 时不会出现在扩展页面列表中。 |
| `sfc` | string | 否 | 运行时 Vue 单文件页面路径，也可用 `component` 代替。 |
| `component` | string | 否 | `sfc` 的别名。 |
| `entry` | string | 否 | 已构建或手写的 JS 入口文件路径。 |
| `html` | string | 否 | 静态 HTML 文件路径。 |
| `style` | string/array | 否 | 外部 CSS 文件路径，单个或多个均可。 |
| `styles` | array | 否 | 外部 CSS 文件路径数组。 |
| `version` | string | 否 | 资源版本号，会追加到资源 URL 后，例如 `?v=1.0.0`，用于刷新缓存。 |
| `props` | object | 否 | 传给页面的自定义配置，可通过 `dtsoftSdk.props` 或 `pageProps` 获取。 |
| `globalName` | string | 否 | JS 入口没有调用注册方法时，可通过全局变量名读取页面定义。 |

每个页面至少要配置 `sfc`、`entry`、`html` 中的一种，否则不会被加载。

资源路径规则：

- 相对路径基于 `manifest.json` 所在目录，例如 `demo/index.vue`。
- 支持绝对路径，例如 `/custom-pages/demo/index.vue`。
- 支持完整 URL，例如 `https://example.com/page.js`。
- 支持 `data:` URL。

## 页面开发方式

当前支持三种开发方式：

| 方式 | manifest 字段 | 适合场景 |
| --- | --- | --- |
| 运行时 Vue 页面 | `sfc` 或 `component` | 轻量业务页、表单、列表、看板，推荐优先使用。 |
| 静态 HTML 页面 | `html`，可配 `style` | 说明页、公告页、静态嵌入内容。 |
| JS 入口页面 | `entry`，可配 `style` | 复杂页面、独立构建产物、需要自定义挂载和卸载逻辑的页面。 |

### 方式一：运行时 Vue 页面

示例目录：

```text
public/custom-pages/
  manifest.json
  demo/
    index.vue
```

manifest：

```json
{
  "pages": [
    {
      "name": "demo",
      "path": "index",
      "title": "自定义页面示例",
      "icon": "Document",
      "sfc": "demo/index.vue",
      "version": "1.0.0"
    }
  ]
}
```

`demo/index.vue`：

```vue
<template>
  <div class="demo-page">
    <div class="demo-page__toolbar">
      <h2>{{ title }}</h2>
      <el-button type="primary" @click="loadData">加载数据</el-button>
    </div>

    <el-table :data="rows" border>
      <el-table-column prop="name" label="名称" />
      <el-table-column prop="status" label="状态" />
    </el-table>
  </div>
</template>

<script>
export default {
  props: {
    dtsoftSdk: {
      type: Object,
      required: true
    },
    pageConfig: {
      type: Object,
      default: () => ({})
    },
    pageProps: {
      type: Object,
      default: () => ({})
    }
  },
  data() {
    return {
      title: '自定义业务页',
      rows: []
    }
  },
  methods: {
    async loadData() {
      try {
        const response = await this.dtsoftSdk.http.get(this.pageProps.apiUrl || '/api/Demo/List')
        this.rows = response.data?.Data || response.data || []
        this.dtsoftSdk.ui.message.success('加载完成')
      } catch (error) {
        this.dtsoftSdk.ui.message.error(error?.message || '加载失败')
      }
    }
  }
}
</script>

<style>
.demo-page {
  padding: 20px;
}

.demo-page__toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  margin-bottom: 16px;
}
</style>
```

运行时 Vue 页面支持：

- `<template>`。
- 普通 `<script>` 中的 `export default { ... }`。
- `<style>`，样式会注入到页面。
- Vue 3 Options API。
- Element Plus 组件，例如 `el-button`、`el-table`、`el-form`。
- Element Plus Icons 图标组件。
- 通过 `dtsoftSdk` 调用主系统能力。

运行时 Vue 页面不支持：

- `<script setup>`。
- TypeScript。
- `import` / `export` 模块导入。
- Less、Sass 等预处理器。
- scoped CSS 的自动哈希隔离。
- 编译期插件、自动导入、别名导入。

如果需要复杂依赖、模块化开发、TypeScript 或打包优化，建议使用 JS 入口页面。

### 方式二：静态 HTML 页面

manifest：

```json
{
  "pages": [
    {
      "name": "notice",
      "path": "index",
      "title": "公告页",
      "html": "notice/index.html",
      "style": "notice/index.css",
      "version": "1.0.0"
    }
  ]
}
```

`notice/index.html`：

```html
<section class="notice-page">
  <h2>系统公告</h2>
  <p>这里是交付现场可以直接维护的公告内容。</p>
</section>
```

`notice/index.css`：

```css
.notice-page {
  padding: 24px;
  background: #fff;
}
```

静态 HTML 页面只负责把 HTML 插入当前页面容器。如果还需要调用接口、路由跳转或动态交互，应改用运行时 Vue 页面或 JS 入口页面。

### 方式三：JS 入口页面

JS 入口适合已经单独构建的页面，也适合手写更底层的挂载逻辑。

manifest：

```json
{
  "pages": [
    {
      "name": "report",
      "path": "index",
      "title": "报表页",
      "entry": "report/index.js",
      "style": "report/index.css",
      "version": "1.0.0"
    }
  ]
}
```

`report/index.js` 可以注册 `component`、`mount` 或 `render`。

注册 Vue 组件：

```js
window.DTSoftCustomPages.register('report', {
  component: {
    props: {
      dtsoftSdk: {
        type: Object,
        required: true
      }
    },
    data() {
      return {
        title: '报表页'
      }
    },
    template: `
      <div style="padding: 20px;">
        <h2>{{ title }}</h2>
        <el-button type="primary" @click="dtsoftSdk.ui.message.success('OK')">
          测试
        </el-button>
      </div>
    `
  }
})
```

自定义挂载：

```js
window.DTSoftCustomPages.register('report', {
  mount(container, dtsoftSdk) {
    container.innerHTML = `
      <div style="padding: 20px;">
        <h2>报表页</h2>
        <button id="reportBack">返回</button>
      </div>
    `

    const button = container.querySelector('#reportBack')
    const onClick = () => dtsoftSdk.router.back()
    button.addEventListener('click', onClick)

    return () => {
      button.removeEventListener('click', onClick)
      container.innerHTML = ''
    }
  }
})
```

返回字符串：

```js
window.DTSoftCustomPages.register('report', {
  render(dtsoftSdk) {
    return `<div style="padding: 20px;">当前用户：${dtsoftSdk.auth.getUserAccount() || '-'}</div>`
  }
})
```

也可以不调用 `register`，改为配置 `globalName`：

```json
{
  "name": "report",
  "path": "index",
  "entry": "report/index.js",
  "globalName": "ReportCustomPage"
}
```

```js
window.ReportCustomPage = {
  render() {
    return '<div style="padding: 20px;">报表页</div>'
  }
}
```

JS 页面定义优先级：

1. `sfc` 解析出来的 Vue 组件。
2. `window.DTSoftCustomPages.register(name, definition)` 注册的定义。
3. `globalName` 指向的全局变量。

页面定义支持：

| 字段 | 说明 |
| --- | --- |
| `component` | Vue 组件对象。主应用会用内置 `mountVue` 挂载。 |
| `mount(container, dtsoftSdk)` | 自定义挂载函数，可返回卸载函数，或返回带 `unmount()` 方法的对象。 |
| `render(dtsoftSdk)` | 返回 HTML 字符串，主应用会插入容器。 |

## dtsoftSdk 内置能力

自定义页面会获得 `dtsoftSdk`。运行时 Vue 页面中通过 prop 获取；JS 入口页面的 `mount`、`render` 中通过参数获取。

### 基础信息

```js
dtsoftSdk.version
dtsoftSdk.page
dtsoftSdk.props
dtsoftSdk.container
dtsoftSdk.route()
```

说明：

| API | 说明 |
| --- | --- |
| `version` | SDK 版本，当前为 `1.0.0`。 |
| `page` | 当前页面配置，包含标准化后的 `name`、`pageKey`、`routePath`、资源路径、`props`、`raw` 等。 |
| `props` | manifest 中配置的 `props`。 |
| `container` | 当前页面挂载 DOM 容器。 |
| `route()` | 当前 Vue Router 路由对象。 |

### HTTP 请求

```js
dtsoftSdk.http.get('/api/Menu/GetMenu')
dtsoftSdk.http.post('/api/Demo/Save', data)
```

`dtsoftSdk.http` 是主系统统一 Axios 实例，具备：

- 统一超时时间。
- 自动显示和结束顶部进度条。
- 非公开接口自动携带 `Authorization: Bearer <token>`。
- `401` 或未授权业务响应时自动清理登录状态并跳转登录页。

接口路径建议继续使用主系统约定的 `/api/...` 前缀。

### 登录与用户

```js
const token = dtsoftSdk.auth.getToken()
const account = dtsoftSdk.auth.getUserAccount()
const loggedIn = dtsoftSdk.auth.isAuthenticated()
dtsoftSdk.auth.clearAuthSession()
```

| API | 说明 |
| --- | --- |
| `getToken()` | 获取当前登录 Token。 |
| `getUserAccount()` | 获取当前登录账号。 |
| `isAuthenticated()` | 判断当前是否存在有效登录态信息。 |
| `clearAuthSession()` | 清理本地登录状态。一般只在明确需要退出或重置登录态时使用。 |

### 路由跳转

```js
dtsoftSdk.router.push('/welcome')
dtsoftSdk.router.replace({ path: '/login' })
dtsoftSdk.router.back()
const currentRoute = dtsoftSdk.router.current()
```

| API | 说明 |
| --- | --- |
| `push(...args)` | 调用主应用 `router.push`。 |
| `replace(...args)` | 调用主应用 `router.replace`。 |
| `back()` | 浏览器历史返回。 |
| `current()` | 获取当前路由对象。 |

### UI 反馈

```js
dtsoftSdk.ui.message.success('保存成功')
dtsoftSdk.ui.message.error('保存失败')

await dtsoftSdk.ui.confirm('确认删除？', '提示', {
  type: 'warning'
})

await dtsoftSdk.ui.alert('操作完成', '提示')

dtsoftSdk.ui.notify({
  title: '通知',
  message: '任务已完成',
  type: 'success'
})
```

| API | 来源 | 说明 |
| --- | --- | --- |
| `message` | `ElMessage` | 成功、失败、警告、普通消息。 |
| `confirm` | `ElMessageBox.confirm` | 确认弹窗。 |
| `alert` | `ElMessageBox.alert` | 提示弹窗。 |
| `notify` | `ElNotification` | 通知。 |

### 隔离存储

```js
dtsoftSdk.storage.local.set('filter', JSON.stringify({ keyword: 'demo' }))
const filter = dtsoftSdk.storage.local.get('filter')
dtsoftSdk.storage.local.remove('filter')

dtsoftSdk.storage.session.set('tab', 'today')
const tab = dtsoftSdk.storage.session.get('tab')
dtsoftSdk.storage.session.remove('tab')
```

| API | 说明 |
| --- | --- |
| `storage.local` | 基于 `window.localStorage`，按页面名称自动加命名空间。 |
| `storage.session` | 基于 `window.sessionStorage`，按页面名称自动加命名空间。 |
| `get(key)` | 读取字符串。 |
| `set(key, value)` | 写入字符串。 |
| `remove(key)` | 删除。 |

命名空间格式为：

```text
dtsoft:custom:<页面 name>:<key>
```

注意：存储值不会自动 JSON 序列化。对象需要手动 `JSON.stringify`，读取后手动 `JSON.parse`。

### 内置库

```js
const { Vue, ElementPlus, ElementPlusIconsVue } = dtsoftSdk.libs
```

| API | 说明 |
| --- | --- |
| `libs.Vue` | Vue 3 完整运行时。 |
| `libs.ElementPlus` | Element Plus 插件。 |
| `libs.ElementPlusIconsVue` | Element Plus 图标集合。 |

### 挂载 Vue 组件

```js
const unmount = dtsoftSdk.mountVue({
  props: {
    dtsoftSdk: {
      type: Object,
      required: true
    }
  },
  template: '<el-button @click="dtsoftSdk.router.back()">返回</el-button>'
})

// 需要销毁时
unmount()
```

`mountVue(component, props)` 会：

- 创建新的 Vue 应用。
- 自动传入 `dtsoftSdk`、`pageConfig`、`pageProps`。
- 安装 Element Plus。
- 注册 Element Plus Icons。
- 注入 `dtsoftSdk`。
- 挂载到当前自定义页面容器。
- 返回卸载函数。

组件内还可以通过以下全局属性访问：

```js
this.$http
this.axios
this.$dtsoft
```

## 能做哪些开发

自定义页面适合开发：

- 客户现场定制首页、欢迎页、说明页。
- 业务看板、统计卡片、图表容器。
- 简单 CRUD 列表、查询条件、详情展示。
- 调用已有后端接口的业务页面。
- 外部系统跳转入口或状态展示页。
- 报表查询页、导出入口页。
- 针对不同交付现场的轻量功能补丁。
- 与菜单权限绑定的客户专属页面。

不建议把以下内容放在自定义页面中：

- 敏感权限判断。
- 密钥、私钥、固定 Token。
- 复杂核心业务规则。
- 大型前端工程。
- 需要严格代码审计和统一发布流程的核心功能。

这些内容应放到后端或主应用正式模块中。

## 样式建议

自定义页面运行在主应用内部，建议：

- 样式类名增加业务前缀，例如 `.customer-report-page`，降低污染主系统样式的风险。
- 不直接覆盖 `body`、`html`、`.el-*` 这类全局选择器。
- 页面最外层设置自己的 padding、背景和布局。
- 多个页面共用样式时，用 `style` 或 `styles` 引入独立 CSS 文件。
- 暗色模式或主题适配优先使用主系统已有 CSS 变量。

运行时 `.vue` 的 `<style>` 不是 scoped，选择器会注入到全局页面中，需要自行控制命名空间。

## 缓存与版本

自定义页面和样式加载时会使用 `version` 追加查询参数：

```text
demo/index.vue?v=1.0.0
demo/index.css?v=1.0.0
```

每次发布修改页面后，建议同步更新 manifest 中对应页面的 `version`，例如：

```json
{
  "version": "1.0.1"
}
```

manifest 本身读取时会追加时间戳并禁用缓存，页面资源则主要依赖 `version` 刷新缓存。

## 调试方式

本地开发：

```bash
npm run serve
```

访问：

```text
http://localhost:8080/#/custom/demo/index
```

排查顺序：

1. 检查 `manifest.json` 是否是合法 JSON。
2. 检查页面是否配置了 `sfc`、`entry` 或 `html`。
3. 检查资源路径是否相对 `manifest.json` 所在目录。
4. 检查浏览器 Network 中页面资源是否 200。
5. 检查 Console 中是否有脚本解析、接口或样式加载错误。
6. 菜单里看不到页面时，进入菜单配置页面重新打开扩展页面下拉，系统会强制刷新 manifest。

常见错误：

| 现象 | 可能原因 |
| --- | --- |
| 提示“未找到自定义页面配置” | 菜单路径和 manifest 中的 `name`、`path` 不一致，或页面 `enabled: false`。 |
| 提示“自定义 Vue 页面加载失败” | `sfc` 路径错误、文件不存在、服务器未发布该文件。 |
| 提示“自定义 Vue 页面脚本解析失败” | `.vue` 中使用了 `import`、`script setup`、TypeScript 或语法错误。 |
| 页面有 HTML 但按钮无效 | 静态 HTML 不会自动绑定 Vue 事件，应使用 Vue 页面或 JS 入口。 |
| 样式影响主系统 | CSS 选择器过宽，建议增加页面级命名空间。 |

## 安全注意事项

自定义页面最终运行在浏览器中，代码和接口路径都能被用户查看。必须遵守：

- 不在前端保存密钥、私钥、数据库连接串。
- 不在自定义页面中实现最终权限判断。
- 后端接口必须自行校验登录态、角色和数据权限。
- 不信任前端传入的用户账号、角色、组织等参数。
- 外部 URL、HTML 字符串、用户输入内容需要谨慎处理，避免 XSS。
- `render()` 返回的 HTML 会直接插入 DOM，不要拼接未清洗的用户输入。

## 发布检查清单

发布前建议逐项检查：

- `manifest.json` JSON 格式正确。
- 页面 `name`、`path` 与菜单路径一致。
- 页面配置了 `title`，方便菜单配置时识别。
- 至少配置了 `sfc`、`entry`、`html` 中的一项。
- 所有资源文件都已放到 `custom-pages` 对应目录。
- 修改后已更新 `version`。
- 页面在目标角色权限下可见。
- 浏览器刷新后页面能正常加载。
- 接口异常、未登录、无权限场景有基本提示。
- 没有在前端写入敏感信息。
